### 权限与发布保护

发布保护各环节的要求见 [05](./05-publish-handoff.md#发布保护)。与工作流有关的几条：

- 候选任务（PR 校验）没有生产分支、部署或图片存储的写权限；社区 PR 不需要 Cloud 凭据。
- 普通作者不能直接推送、强推正式生成分支，也不能绕过检查。
- 工作流和校验器的改动需工程审核，内容 PR 不能关闭保护。
- 用 `GITHUB_TOKEN` 推送的提交不会自动触发其他工作流，凡是工具推送的提交都要显式触发校验。

具体的分支保护规则、各工作流的 `permissions` 设置：待补。

### 仓库准备

- PR 标签 `shared-docs: not-launched` 由 zdoc 维护者在仓库中预先创建。
- 其他一次性配置（分支保护、必需的检查项等）：待补。
